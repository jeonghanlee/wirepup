# ADR-0000: License WirePup under Apache License 2.0

Status: Accepted

## Context

WirePup is intended to be a reusable open-source engineering tool. The project may later be used by universities, laboratories, research institutions, companies, and external contributors.

A permissive license is preferred.

## Decision

Use the **Apache License 2.0**.

SPDX identifier:

```text
Apache-2.0
```

## Rationale

Apache-2.0:

- permits commercial and non-commercial use;
- permits modification and redistribution;
- provides explicit patent-license language;
- is widely understood in engineering/software organizations;
- does not require derivative works to be distributed under the same license.

## Consequences

- source distributions must retain required notices/license information;
- third-party dependencies must have compatible licenses;
- a dependency/license inventory should be maintained as the project grows.

## Note

This ADR records a project engineering choice, not legal advice.
