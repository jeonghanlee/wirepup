# Closed Doors

Candidates a review examined and the owner left unchanged. Each row records
the Keep verdict and its premise so that a later review can close the same
door in seconds instead of re-opening it. The carrying commit of a row is the
commit that introduced it (`git log --follow docs/CLOSED_DOORS.md`).
M-numbers refer to `docs/milestone-182961f.md`.
